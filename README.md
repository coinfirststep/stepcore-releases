# Stepcore · Crypto Auto-Trading

**Stepcore** is a free auto-trading desktop app for Binance spot and USDⓈ-M futures (Windows · Mac). This repository hosts the installers.

[한국어 안내 ↓](#한국어)

## Download

1. Open the [latest release](https://github.com/coinfirststep/stepcore-releases/releases/latest).
2. Download the one file that matches your PC.

| File | PC |
| --- | --- |
| `Stepcore-…-mac-arm64.dmg` | Mac (Apple chip: M1 or later) |
| `Stepcore-…-mac-x64.dmg` | Mac (Intel chip) |
| `Stepcore-…-win-x64.exe` | Windows (most PCs) |
| `Stepcore-…-win-arm64.exe` | Windows (ARM laptops) |

- Mac: Apple menu → [About This Mac] → "Chip: Apple M…" = arm64 · "Processor: Intel" = x64
- Windows: Settings → System → About → "System type" says ARM = arm64 · otherwise x64

## First-open warning

The app is free and not signed, so your system warns you the first time. Open only files downloaded from this page, like this:

| PC | Steps |
| --- | --- |
| Mac (macOS 15 or later) | Open the dmg and drag Stepcore to Applications → open Stepcore → [Done] on the warning → System Settings → Privacy & Security → [Open Anyway] next to "Stepcore" → [Open Anyway] in the window that appears → password |
| Mac (macOS 13 · 14) | Open the dmg and drag Stepcore to Applications → in Applications, Control-click (right-click) Stepcore → [Open] → [Open] again |
| Windows | If your browser warns the file is not commonly downloaded, choose [Keep] (Edge: … → [Keep] → [Show more] → [Keep anyway]) → run the exe → on "Windows protected your PC" click [More info] → [Run anyway] |

- After the first time, it opens normally.

## Updates

- When the app shows a new version, download the new installer from this page and install it over the old one. Your settings, strategies, records and API keys stay on your PC.

## Safety

- Your API keys are encrypted and stay on your PC. They are never sent to any other server.
- Keep Enable Withdrawals turned off on your Binance API key. The app has no transfer or withdrawal feature.
- Anyone asking for your seed phrase, wallet password, a deposit or remote access is a scammer.
- No profit is guaranteed. The app runs the strategy you build.

### 안전

- API 키는 내 PC에만 암호화해 둡니다. 다른 서버로 보내지 않습니다.
- 바이낸스 API 키의 출금 권한(Enable Withdrawals)은 끈 채로 둡니다. 앱에는 이체 · 출금 기능이 없습니다.
- 시드 문구 · 지갑 비밀번호 · 입금 · 원격 접속을 요구하면 가짜입니다.
- 수익을 보장하지 않습니다. 프로그램은 내가 만든 전략을 실행하는 도구입니다.
